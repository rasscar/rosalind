# Rosalind Solutions — Go (Golang)

Kumpulan solusi untuk tantangan bioinformatika di [Rosalind.info](https://rosalind.info/), ditulis menggunakan bahasa **Go (Golang)**.

![Go](https://img.shields.io/badge/Language-Go-00ADD8?logo=go)
![Rosalind](https://img.shields.io/badge/Platform-Rosalind.info-blue)

---

## 📖 Tentang

Repository ini berisi solusi pribadi untuk problem-problem Rosalind sebagai sarana latihan bioinformatika komputasional dan penulisan kode Go.

Setiap solusi berupa file Go mandiri (`package main`) yang membaca input dari `stdin` atau file dataset, lalu mencetak hasil ke `stdout`.

---

## 🚀 Menjalankan

```bash
# Input dari terminal
echo "<input>" | go run <file>.go

# Input dari file dataset
go run <file>.go < dataset.txt
